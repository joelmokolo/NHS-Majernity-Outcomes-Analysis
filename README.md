# NHS Maternity Outcomes Analysis — MSDS Data

## Project Aim
This project analyses NHS maternity-style data to understand booking patterns, antenatal attendance, maternity outcomes and data quality issues.

## Why This Project Matters
The Information Analyst role I am targeting focuses on maternity data and the Badgernet clinical system. This project helps me build practical understanding of maternity reporting, MSDS-style data, SQL analysis and data quality validation.

## Business Questions
- What percentage of patients were booked within 10 weeks?
- Which trusts or services show missing booking information?
- What are the common delivery types?
- What percentage of births were preterm?
- Are there missing or invalid values affecting reporting quality?
